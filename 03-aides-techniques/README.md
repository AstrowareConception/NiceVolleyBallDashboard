# Aides techniques

Cette section regroupe les aides techniques produites pour accompagner les étudiants pendant les semaines intensives.

## Aides disponibles

- [Slim / API PHP](aide-slim-api-php.md)
- [JavaScript vanilla + fetch](aide-javascript-vanilla-fetch.md)
- [MERISE / données](aide-merise-donnees.md)

## Utilisation recommandée

### Backend

Commencer par l'aide Slim pour comprendre :

- la structure du backend ;
- les routes REST ;
- les réponses JSON ;
- la connexion PostgreSQL ;
- les services externes ;
- la gestion des erreurs.

### Frontend

Utiliser l'aide JavaScript pour :

- organiser les fichiers ;
- appeler l'API avec `fetch()` ;
- afficher des tableaux ;
- gérer les formulaires ;
- traiter les erreurs ;
- éviter les clés API dans le navigateur.

### Données

Utiliser l'aide MERISE pour :

- formaliser les règles de gestion ;
- produire MCD/MLD ;
- préparer les scripts SQL ;
- intégrer contacts, événements, billets, segments et consentements ;
- préparer les preuves BTS SIO.
