# Phase 3 — Déploiement SISR

## Objectif

La phase 3 est destinée aux étudiants SISR. Elle consiste à prendre l'application finalisée par les SLAM, fournie sous forme d'image Docker, puis à la déployer sur le VPS du client.

## Point d'entrée

Les SISR doivent commencer par lire :

- [Passation technique vers les SISR](../02-semaine-2-finalisation-slam/passation-sisr.md)
- [Image Docker livrable](../02-semaine-2-finalisation-slam/image-docker-livrable.md)

## Objectifs techniques

- obtenir ou vérifier les accès VPS ;
- sécuriser SSH ;
- installer Docker et Docker Compose ;
- déployer l'image ;
- configurer les variables d'environnement ;
- configurer reverse proxy et HTTPS ;
- mettre en place sauvegardes et restauration ;
- documenter l'exploitation ;
- vérifier la disponibilité du service.
