## Usage attendu

Chaque outil doit servir à prendre des décisions :

- que fait-on absolument ?
- qui est responsable ?
- qu'est-ce qui bloque ?
- qu'est-ce qui est reporté ?
- qu'est-ce qui est prêt pour la recette ?

## Rythme conseillé

- début de journée : objectifs et priorités ;
- milieu de journée : dépendances entre pôles ;
- fin de journée : avancement, blocages, arbitrages, preuves.
