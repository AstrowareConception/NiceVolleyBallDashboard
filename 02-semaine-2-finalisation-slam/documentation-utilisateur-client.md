# Documentation utilisateur client

La documentation utilisateur doit permettre au club d'utiliser le dashboard sans connaissance technique.

## Plan conseillé

1. accès au dashboard ;
2. rôle de l'outil ;
3. synchroniser Weezevent ;
4. consulter un événement ;
5. exporter les contacts d'un événement ;
6. identifier les nouveaux spectateurs ;
7. gérer les invitations si disponibles ;
8. envoyer ou synchroniser vers Brevo ;
9. comprendre consentement et désinscription ;
10. limites connues.

## Règles de rédaction

- phrases courtes ;
- captures d'écran légendées ;
- vocabulaire non technique ;
- aucune clé API ;
- aucune donnée personnelle réelle visible sans anonymisation.
